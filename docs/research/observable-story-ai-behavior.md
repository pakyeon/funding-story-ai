# 관찰 가능한 Story AI 동작

이 문서는 선행 비공개 PoC에서 구현 설계에 사용한 관찰만 요약한다. 원본 대화,
스크린샷과 HTML은 이 저장소에 포함하지 않는다.

## 공개 정보에서 확인한 구조

와디즈 공식 기술 글과 공개 템플릿 화면은 다음 의미 영역을 설명한다.

- 성공 스토리 패턴을 구조화 템플릿으로 관리
- 카테고리, 타깃, 내레이션, 스타일과 콘텐츠 전략
- 톤 키워드, 문장 스타일, 색상, 강조 문구
- 역할·기대 콘텐츠·비주얼 힌트가 있는 순서형 섹션 골격
- 제품 분석, 템플릿 검색, 본문·이미지 생성과 미리보기
- 21개 카테고리와 102개 참조 템플릿, 카테고리 soft boost

공개 정보는 내부 JSON 키, 실제 프롬프트, 모델, 검색 점수와 템플릿 원본을 제공하지
않는다.

## 정상 UI에서 관찰한 동작

로봇청소기 중심의 제한된 실행에서 다음 외부 상태가 확인됐다.

- 최초 제품 설명과 선택적 이미지 입력
- 특장점·타깃 질문
- 시험·인증·후기 등 신뢰 요소와 메이커·팀 질문
- 네 필드를 한 번에 묻는 통합 질문
- 입력 요약과 생성 확인
- 질문 건너뛰기 뒤 생성
- 동일 입력에서도 후속 질문 또는 바로 생성으로 달라진 사례
- 10~13개의 결과 역할과 2~6개의 이미지로 변동

이 관찰만으로 실제 분기 원인, 확률, 내부 템플릿 ID나 모델 호출 구조를 식별할 수 없다.

## 현재 구현에 반영한 방식

- 질문 필드 이름 대신 제품군 독립 의미 슬롯을 사용한다.
- 질문 결정은 고정 제품군 profile이 아니라 대화 LLM에 맡기고, 템플릿은 생성 골격으로만 사용한다.
- 통합 질문과 순차 질문을 모두 표현할 수 있다.
- 비결정적인 자동 생성을 복제하지 않고 명시적 확인을 기본값으로 사용한다.
- 미입력 사실을 채우는 동작은 기능 동등성보다 사실성을 우선해 제외한다.

따라서 이 프로젝트는 관찰 가능한 기능에서 영감을 받은 독립 구현이며 특정 서비스의
내부 구조 복원본이 아니다.
