# 선행 PoC·로직 증류 평가 요약

이 문서는 선행 비공개 실험의 구현 결정에 필요한 결론만 보존한다. 외부 서비스 원문
출력, 사용자 계정 정보, 실행 원장과 이미지 산출물은 이 저장소로 복사하지 않았다.

## 1차 검증

- 범위: 한국어 로봇청소기
- 정식 비교: E01~E08
- 단위: 같은 최종 입력 정보의 외부 기준 결과와 로컬 결과
- 1차 평가: Codex, 최종 판단: 사용자

| 지표 | 당시 결과 |
|---|---:|
| 관찰 핵심 질문·확인·생성 상태 | 8/8 |
| E03~E08 관찰 경로 회귀 재생 | 6/6 |
| 제한된 Behavioral Parity | 89/100 |
| 외부 기준 평균 품질 | 76.6/100 |
| 로컬 평균 품질 | 88.9/100 |
| run-level 미입력 사실 생성 | 외부 8/8, 로컬 0/8 |

E01·E02만 전수 claim-level 라벨링했고 나머지는 중요 주장 중심으로 판정했다. 따라서
마지막 행을 전체 claim의 발생 비율로 해석할 수 없다. 89점도 현재 저장소나 다른
제품군의 동등성 점수가 아니다.

## 2차 검증

2차 범위는 공개 구조에서 확인된 worker, MCP tool layer, executor, template retrieval와
결과 규격을 하나의 경로로 연결하는 것이었다.

- 개발 실행: N01~N08
- holdout: N09
- N10: 미실행·미승인
- 실행 경로: worker → FastMCP → retrieval → executor → text/images/HTML
- 검색 집합: 16후보, 실행 가능 6개
- 검색 방식: exact cosine KNN + category boost 0.1

N09는 전체 로컬 실행 경로와 12-section·3-image 결과 생성을 완료했다. 로컬 검색은
`t06_trust_maintenance_full_campaign`을 선택했고 결과 경고는 0개였다. 다만 동일 입력에서
외부 기준은 확인 단계로 이동한 반면 실험용 로컬 재생기는 보조 정보 질문으로 이동했다.
따라서 결론은 전면 동등이 아니라 **조건부 진행**이었다.

## 제품 저장소에 반영한 결정

| 실험 결과 | 제품 반영 |
|---|---|
| 대화와 실행기 책임 분리 | `worker.py`와 `engine.py` 분리 |
| worker의 생성 도구 제한 | FastMCP allowlist 1개 |
| SSE보다 현재 권장 전송 채택 | Streamable HTTP만 구현 |
| 검색 후보와 실행 템플릿 분리 | 16 candidates / 6 executable |
| 공통 출력 비교 필요 | 모든 실행 템플릿을 12 section으로 정렬 |
| N09 질문 분기 불일치 | `explicitly-absent`를 답변 완료로 처리 |
| 이미지·텍스트 결과 연결 | integrated run schema와 SHA-256 |
| 실험 replay override 위험 | N07/E02 전용 override 제거 |

제품 보정 후 같은 외부 기준으로 다시 실행하지 않았으므로 질문 분기가 해결됐다는 것은
로컬 회귀 계약에 대한 주장이다. 외부 동등성 재확인은 다음 실험 과제다.

## 비용 해석

선행 실험 비용 숫자는 특정 시점·계정·모델 설정의 기록으로 제품 기본 예산이 아니다.
이 저장소는 개인 상한을 하드코딩하지 않고 `.env`에서 Gemini와 OpenAI 상한을 각각
설정한다. 모든 금액은 추정치이며 실제 Billing과 별도로 확인해야 한다.

## 해석 제한

- 단일 제품군과 단일 holdout
- 단일 1차 평가자
- 외부 기준의 내부 프롬프트·모델·검색 미확인
- 품질 점수의 자동 재현 도구 미포함
- 실제 펀딩 게시, 광고 심사와 성과 미검증
