# 현재 한계

## 검증 범위

- 질문·품질 비교는 한국어 로봇청소기 한 제품군에 한정된다.
- 6개 실행 템플릿은 모두 같은 12-section 골격을 쓰므로 레이아웃 다양성은 검증하지 않았다.
- 검색 index 16개는 KNN과 soft boost 기술 검증용 축소 집합이다.
- N09 holdout에서 대화 분기 불일치가 발견되었고 제품 규칙으로 보정했지만 외부 기준과
  재비교하지 않았다.
- 다중 평가자 블라인드 평가, 실제 게시·편집 시간과 전환 성과를 검증하지 않았다.

## 서버와 저장소

- FastMCP 서버는 local loopback 전용이다.
- `LocalRunStore`는 단일 프로세스 개발용이며 DB transaction이나 프로세스 간 lock이 없다.
- 사용자 인증, 권한 분리, 암호화, 보존 정책, webhook callback을 제공하지 않는다.
- 웹 대화 UI와 장기 대화 session 저장소는 포함하지 않는다.

## 모델과 비용

- 기준 텍스트 모델은 `gemini-3.7-flash`, 폴백은 `gemini-3.6-flash`다.
- Gemini 3.7 기본 추정은 2026-12-31까지의 공개 도입 단가를 사용한다.
- 모델 가격, 환율, 이미지 토큰 환산은 변경될 수 있다.
- 원장은 API 응답 기반 추정치이며 실제 Billing·크레딧 적용 내역과 일치한다고 보장하지 않는다.
- embedding 호출 비용은 현재 story usage 요약과 별도이며 통합 원장에 합산하지 않는다.

## 사실성과 규정

- 자동 검증은 외부 사실 검색을 수행하지 않는다.
- 메이커가 입력한 허위 정보 자체를 판별할 수 없다.
- 정규식·source field 검사는 알려지지 않은 표현의 환각을 모두 잡지 못한다.
- 광고법, 플랫폼 심사, 인증 표시와 지식재산권 판단은 사람 검토가 필요하다.
- 생성 이미지가 실제 양산 제품과 일치하거나 권리 침해가 없다고 보증하지 않는다.

## 연구 해석

- 외부 서비스의 비공개 프롬프트, 모델, 템플릿 원본과 검색 파라미터를 복원하지 않았다.
- 공개된 구성 요소와 관찰 가능한 입출력으로 책임 경계를 독립 구현했다.
- 공통 12-section 골격은 제한된 관찰과 구조 연구의 결과이며 내부 직렬화와 동일하다는
  주장이 아니다.
- 성공 프로젝트에서 반복된 구조는 성과의 원인이 아니라 후보 근거다.
